# 更新与恢复

从已公开可下载的版本收集玩家可见的变化。检查拟公开的提交和实际 ZIP，确认 GitHub Release 中的 `kcd1db.zip` 可下载。记录 Nexus 主文件稳定 ID。触发前查公开 Files 页面和同一 tag 的 Actions run，每次成功上传会新增一个文件版本。

| 当前状态 | 下一步 |
| --- | --- |
| 目标版本已公开 | 核对下载并接续获授权的页面工作。 |
| 对应 run 正在排队或运行 | 跟踪该 run 与公开 Files 页。 |
| 触发未返回 run ID | 按标签、标题和时间定位 run，再查 Files 页。 |
| run 在上传前失败 | 修正失败步骤并确认目标版本缺失后重试。 |
| 上传步骤中断或后续步骤失败 | 查公开 Files、上传步骤和 run 摘要，确认效果后决定是否重试。 |
| 上传成功但公开页面尚未更新 | 等待目标版本出现在 Files 页。 |

保留已确认的 run ID 和公开版本。只修文件说明时，先检查 Nexus 现有条目的编辑入口。对同一版本重新触发上传也会新增版本记录。完成后验证本次要求更新的公开页面和 GitHub、Nexus 下载。
