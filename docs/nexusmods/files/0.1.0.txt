Initial release of kcd1db for Kingdom Come: Deliverance. Provides SQLite persistence for Lua mods, with save-local snapshots and cross-save settings. Supports Windows x64 Steam build 1.9.8-404-504czj4 (BuildID 22623230). Extract kcd1db.asi beside KingdomCome.exe in Bin/Win64 and use the x64 Ultimate ASI Loader. Keep kcd1db.db with your save backups to preserve mod data.
